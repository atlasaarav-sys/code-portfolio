# 01 — Python Basics & Syntax

**Language:** Python 3
**Level:** Beginner

## What this demonstrates

- Variables, types, f-strings
- Control flow (if/elif/else, for, while)
- Functions, default args, *args/**kwargs
- Lists, dicts, sets, comprehensions
- Exception handling
- Basic file I/O

## Files

- `basics.py` — syntax tour, run directly
- `fizzbuzz.py` — classic loop/conditional exercise
- `temperature_converter.py` — small function-based exercise with CLI input

## How to run

```bash
python basics.py
python fizzbuzz.py
python temperature_converter.py
```

## Notes

Starting point for the language — no external dependencies.
